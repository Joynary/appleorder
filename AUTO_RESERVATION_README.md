# Apple Store Inventory Monitor — Browser Assist

This repository is prepared to build a Windows version based on the upstream project `suversal/apple-store-inventory-monitor`.

The assisted workflow is intentionally limited to opening the matching Apple product flow and filling preset contact information. It does **not** click a final order/submit button automatically. The user remains responsible for reviewing the store, item, price, and final confirmation before completing the transaction.

See the GitHub Actions workflow under `.github/workflows/build-windows.yml` for the Windows build process.
